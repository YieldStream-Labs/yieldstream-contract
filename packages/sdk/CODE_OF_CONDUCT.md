# Code of Conduct

## Our commitment

YieldStream is a small, distributed open-source project. Contributors arrive
from different time zones, experience levels, and motivations. Everyone
participating in this repository and the
[`yieldstream-org`](https://github.com/yieldstream-org) spaces — issues, pull
requests, discussions, and any official event — agrees to keep the work
technical, welcoming, and safe.

## Expected behaviour

- Assume good intent. A question that seems obvious was obvious to someone who
  already did the harder part.
- Give reasons, not verdicts. "This breaks the RFC 6962 domain separation
  because…" beats "wrong".
- Critique the code, never the person. Feedback on a PR is not feedback on you.
- Respect that review latency is not rejection. The stated bar is 48h to a
  reply and 5 days to a review; ask if we miss it.
- Credit other people's work and do not claim a contribution you did not make.
  Duplicate or fabricated identities are grounds for removal — the Drips Wave
  program this project participates in prohibits them.

## Unacceptable behaviour

Harassment, sexualised or discriminatory language, targeted trolling, doxxing,
sustained disruption of review, and any attempt to game contributor rewards by
submitting the same work under multiple accounts.

## Scope

This policy covers this repository and every other repository under
`yieldstream-org`, including maintainer actions and the decisions about which
contributions get merged and paid.

## Reporting

Report to the org owner, [@CHASE3020](https://github.com/CHASE3020), through a
[private security/advisory form](https://github.com/yieldstream-org/yieldstream-contract/security/advisories/new)
if you would rather not post publicly, or any org admin you trust. Describe
what happened, where, and who was involved.

We commit to:

- acknowledging within 72 hours
- reviewing without the reporter being required to confront the reported person
- keeping the report private to the maintainers unless you consent otherwise
- stating the outcome, and what changes, to the reporter

## Enforcement

Maintenance team responses scale with the severity and pattern: a private
written warning, a temporary mute from project spaces, or removal of access and
of eligibility for contributor rewards. Decisions can be appealed to another
maintainer.
